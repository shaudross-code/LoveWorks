# iLoveWorks

React web app (`frontend/`) + FastAPI backend (`backend/`) + MongoDB, wrapped as native iOS/Android apps with Capacitor.

## Which Xcode project do I open?

➡️ **`frontend/ios/App/App.xcodeproj`** — the App Store app. It shows the exact web app (same look, same features).

`iLoveWorks.xcodeproj` at the repo root is a separate hand-written SwiftUI prototype with its own UI; it will not look like the web app.

Full steps (no CocoaPods or Node required on your Mac): see **[NATIVE_BUILD_GUIDE.md](NATIVE_BUILD_GUIDE.md)**.
Store submission: `STORE_SUBMISSION_GUIDE.md` · Push setup: `PUSH_SETUP_GUIDE.md`.
