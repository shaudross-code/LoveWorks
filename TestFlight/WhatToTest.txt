iLoveWorks: Native UI Parity & Advanced Admin Features 🚀

Welcome to the latest build of iLoveWorks! This massive update brings our native iOS app perfectly in line with the web experience. We have finalized the custom horizontal tab navigation across the entire app and rewritten all of the Admin & Worker modals natively in SwiftUI for blazing-fast performance.

What to Test:
1. Dashboard Tabs: Test the new horizontally scrolling custom tab bar. Verify it matches the website's layout and cleanly switches between sections (Overview, Workers, Tasks, Goals, Announcements, Sizes, Profile).
2. Advanced Editing Modals: In the Admin view, tap on any active Worker, Task, Goal, or Trip card. A custom-themed sheet should appear. Verify all matching web fields are present (Task Frequency, Payout Schedules, Image URLs, Target amounts, etc.).
3. Worker Sizes: Check out the new native "Sizes" tab! Admins can tap on a worker, hit "VIEW & EDIT SIZES", and manage apparel fits and preferences natively while pushing update notifications.
4. Passwords & Profiles: Test editing a worker's profile (name & email) and verify you can securely set a new optional password for them directly from the Admin console.
5. Task Alarms & Push Notifications: Test creating tasks with mandatory Admin alarms. Verify local Push Notifications arrive reliably for scheduled task alarms.
6. Overall UI & Theming: Ensure cards, grid layouts, and padding correctly mirror the website experience across all views.
